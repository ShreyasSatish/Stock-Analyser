# Stock Forecaster/Analyser
My interest in stocks and quantiative finance led me to make this stock analyser. This is a way to load a stock between a desired timeframe and, using an ARIMA model, forecast the stocks future prices. Although the forecasted line doesn't match with the ups and downs of the test data, it does get close to the final price of the stock.
Have a play with the code and analyse other stocks with varying timeframes.
